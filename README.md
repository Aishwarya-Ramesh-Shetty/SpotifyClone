# 🎵 Spotify Clone

A sleek and responsive **Spotify Clone** built using **React + Vite** and styled with **Tailwind CSS**, designed to recreate the core music player experience of Spotify.

This project allows users to enjoy a smooth and interactive music streaming interface with essential playback controls like **Play, Pause, Previous, and Next**, providing a clean and modern UI inspired by the original Spotify platform.

---

## 🚀 Features

✨ Beautiful and responsive UI inspired by Spotify  
▶️ Play songs seamlessly  
⏸️ Pause currently playing tracks  
⏮️ Navigate to previous songs  
⏭️ Skip to next tracks  
🎧 Smooth music player experience  
📱 Fully responsive design for desktop and mobile  
⚡ Fast performance with Vite  

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- JavaScript (ES6+)
